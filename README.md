# MD Photo

تطبيق Flutter لإعداد ورقة صور جاهزة للطباعة، بواجهة عربية، ومقاسات فعلية بالملليمتر.

## المزايا

- تخطيطات من صورة واحدة حتى 16 صورة، مع دعم A4 وA5 والمقاس المخصص.
- اتجاه عمودي أو أفقي، وضبط الهوامش والمسافات وخطوط القص.
- إضافة عدة صور من المعرض أو التقاط صورة بالكاميرا، مع تكرار صورة واحدة على كامل الورقة.
- اضغط على أي صورة مضافة لتحريرها؛ حرّك وكبّر الصورة، دوّرها، اختر القص أو الاحتواء، استبدلها أو احذفها.
- إعادة ترتيب الصور بالسحب والإفلات بين الخانات، مع تأكيد قبل الحذف وتراجع/إعادة للتغييرات.
- معاينة فورية للورقة وملف PDF النهائي قبل الطباعة أو المشاركة.
- تراجع وإعادة حتى 50 خطوة.
- تصدير PDF بمقاس الصفحة الفعلي أو إرساله مباشرة إلى واجهة الطباعة في النظام.
- معالجة الصور وإنشاء PDF محلياً على الجهاز؛ لا تُرفع الصور إلى خدمة خارجية.

## التشغيل

يتطلب Flutter وDart وإعداد Android SDK. يتطلب بناء وتشغيل نسخة iOS جهاز macOS مع Xcode.
تمت إضافة هدف iOS وإعدادات صلاحيات الصور والكاميرا. يبني GitHub Actions نسخة iOS ونسخة لمحاكي iOS، ويرفع نسخة المحاكي كملف `md-photo-ios-simulator` قابل للتنزيل من صفحة تشغيل workflow. نسخة المحاكي تعمل على macOS مع Xcode فقط، ولا تُثبّت على iPhone فعلي.

```bash
flutter pub get
flutter run
```

## التحقق والبناء

```bash
flutter analyze
flutter test
flutter build apk --release
```

لبناء iOS والتحقق منه على macOS:

```bash
flutter build ios --no-codesign
```

## البنية

- `lib/models/`: إعداد الصفحة والخانات.
- `lib/screens/`: محرر الصور وإعدادات الورق.
- `lib/widgets/`: معاينة الورقة التفاعلية.
- `lib/services/`: إنشاء PDF بمقاسات فيزيائية.

Flutter/Dart هو التطبيق الأساسي. ملفات Gradle وKotlin القديمة الموجودة في نسخة العمل المحلية لم تعد نقطة تشغيل التطبيق؛ تطبيق Android الذي يُبنى بواسطة Flutter يستخدم Kotlin فقط كجسر تشغيل Flutter الذي ينشئه Flutter SDK.

## قراءات ومشاريع مرجعية

تمت مراجعة مستودعات وممارسات Flutter المفتوحة عند اختيار هيكل التطبيق وتكامل الصور والطباعة:

- [Flutter packages — image_picker](https://github.com/flutter/packages): اختيار الصور عبر منتقي النظام.
- [DavBfr/dart_pdf](https://github.com/DavBfr/dart_pdf): إنشاء PDF ودمجه مع واجهات الطباعة في Flutter.
- [fluttercandies/extended_image](https://github.com/fluttercandies/extended_image): مرجع مفتوح لتجارب عرض الصور والتحرير والتدوير والقص.
- [hm21/pro_image_editor](https://github.com/hm21/pro_image_editor): مرجع لأنماط أدوات تحرير الصور وتجربة المستخدم.

يستخدم المشروع حالياً حزمتَي `image_picker` و`pdf`/`printing`، بينما رُوعي إبقاء تخطيط الورقة وحساب الأبعاد في كود التطبيق لتكون قياسات الطباعة قابلة للاختبار. وتُحفظ تعديلات الصورة نفسها ضمن بيانات الورقة وتُطبّق على ملف PDF النهائي.
